  1. 找搭子 (Buddy Matching) — P0

  Current: Simple list, no matching logic

    ├── 类型: 学习 / 运动 / 游戏 / 吃饭 / 旅行 / 其他
    ├── 标签: (多选) 考研 / 篮球 / 王者 / 火锅 / 摄影...

    └── 人数: 1人 / 2-3人 / 4人+

  Algorithm:
    1. Filter: Same campus, matching time window
    2. Score: Tag overlap (weight 50%), mutual friends (30%), proximity (20%)
    3. Rank: Score descending
    4. Display: Top 20 matches with "匹配度 85%"

      ├── 送达拍照上传
      └── 双方确认完成

  信任机制:
